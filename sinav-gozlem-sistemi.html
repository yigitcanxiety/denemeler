Sınav Gözlem Sistemi v2

Yakaya takılan düğme kamera + uzaktan gözetmen ekranı ile kağıt sınav davranış kaydı. Stres/duygu/kopya çıkarımı yapılmaz.

Gizlilik ve Etik Sınırlar

Bu sistem YAPMAZ:

  • Stres, duygu veya psikolojik durum çıkarımı
  • Kopya niyeti tespiti veya ima
  • Otomatik öğrenci değerlendirmesi veya puanlama
  • Yüz tanıma veya biyometrik analiz
  • Öğrenciler arası karşılaştırma

Zorunlu: Katılımcılar kayıt amacı hakkında bilgilendirilir. Kayıtlara erişim, saklama ve silme süreleri sınırlandırılır. Kamera yalnızca kağıdı ve eli kaydeder.

Sistem Mimarisi

Öğrencinin yakasına takılan düğme boyutunda bir kamera, ince FPC kablosuyla ceketinin iç cebindeki/kemerine klipslenen verici üniteye bağlıdır. Verici, WiFi üzerinden başka bir odadaki MacBook'a görüntü akışı yapar. MacBook tüm görüntü işleme ve yapay zeka analizini gerçekleştirir, sonuçları kredi kartı boyutundaki kablosuz gözetmen ekranına iletir.

Nasıl Çalışır

Adım Adım Akış

  1. Kamera yakaya takılır — Düğme görünümlü OV2640 modül, kıyafete dikilir/klipslenir. Öğrenci oturduğunda eğimli sıradaki kağıda bakar.
  2. FPC kablo ile verici — 20-30cm ince FPC kablo kıyafetin içinden geçerek cepteki/kemerdeki ESP32-S3 vericiye bağlanır.
  3. WiFi akışı — ESP32-S3, MJPEG akışı ile kare kare görüntüyü WiFi router üzerinden MacBook'a gönderir (5-10 fps, 640×480).
  4. MacBook işler — Python + OpenCV ile el/kalem hareketleri, yazma/duraklama süreleri, sayfa geçişleri, silme hareketleri tespit edilir.
  5. Cevap anahtarı oluşturulur — Tesseract OCR ile yazılan cevaplar okunur, AI destekli cevap anahtarı taslağı çıkarılır.
  6. Gözetmen onaylar — Kredi kartı ekranında cevap anahtarı gösterilir. Gözetmen düğmelerle Onayla/Düzelt/Atla yapar.
  7. İzleme moduna geçiş — Onay sonrası ekran otomatik olarak canlı izleme moduna döner: süre çubukları, aktivite göstergesi, sayfa durumu.

Yazılım Mimarisi

Sistem üç katmanlı bir yazılım mimarisine sahiptir: ESP32 firmware (verici + ekran), Mac Python uygulaması (merkez işleme), ve arabirim protokolleri.

A. ESP32-S3 Verici Firmware

camera_stream.ino Arduino/ESP-IDF

  • OV2640 kamera DVP arayüzü ile başlatma (QVGA 640×480)
  • MJPEG HTTP sunucusu (/stream endpoint)
  • WiFi bağlantı yönetimi (SSID/şifre EEPROM'da)
  • Pil voltajı ADC ölçümü ve düşük pil uyarısı
  • OTA (Over-The-Air) güncelleme desteği
  • Hedef: 5-10 fps, JPEG kalitesi 10-12 (boyut/kalite dengesi)

B. ESP32-C3 Gözetmen Ekranı Firmware

display_client.ino Arduino/ESP-IDF

  • WiFi ile MacBook'a WebSocket bağlantısı
  • ILI9341 TFT sürücü (SPI, 240×320)
  • Mod 1 — Cevap Anahtarı: Soru/cevap çiftleri gösterilir, 3 düğme ile Onayla/Düzelt/Atla
  • Mod 2 — Canlı İzleme: Soru başına süre çubukları, aktivite göstergesi, sayfa durumu
  • Otomatik mod geçişi (cevap anahtarı onaylanınca izleme moduna)
  • Pil durumu göstergesi

C. Mac Python Uygulaması (Hub)

capture.py Python

  • ESP32-S3'ün MJPEG akışından kare yakalama
  • Çoklu kamera desteği (birden fazla öğrenci)
  • Kare arabelleği ve FPS sayacı
  • Bağlantı kopması/yeniden bağlanma yönetimi

frame_analyzer.py Python

  • El ve kalem tespiti (OpenCV kontur analizi)
  • Yazma / duraklama / silme hareket sınıflandırması
  • Hareket yoğunluğu hesaplama (optik akış)
  • Kağıt dörtgenini tespit (perspektif düzeltme)

page_detector.py Python

  • Çoklu sayfa tespiti (kağıt çevirme algılama)
  • OCR tabanlı tekrar tespit (>85% benzerlik = aynı sayfa)
  • Sayfa durumu: PARTIAL / COMPLETE / UNCERTAIN
  • Eğimli masa açısı kompanzasyonu

document_stitcher.py Python

  • Tüm sayfaları birleştirerek tam belge oluşturma
  • OCR ile soru numarası tespiti
  • Sayfa sırası doğrulama

timing_engine.py Python

  • Soru başına zamanlama (yazma süresi, duraklama süresi, silme süresi)
  • Toplam sınav süresi takibi
  • Aktivite zaman çizelgesi oluşturma
  • Olay tabanlı kayıt (WRITE_START, WRITE_END, PAUSE, ERASE, PAGE_TURN)

answer_key.py Python

  • Tesseract OCR ile Türkçe metin çıkarma
  • AI destekli cevap anahtarı taslağı oluşturma
  • Gözetmen onay akışı yönetimi (WebSocket üzerinden)
  • Onaylanan cevap anahtarını veritabanına kaydetme

display_server.py Python

  • WebSocket sunucusu (ESP32-C3 ekranlarla iletişim)
  • Veri paketleme: JSON → kompakt ikili format (ekran için)
  • Mod yönetimi (cevap anahtarı → izleme geçişi)
  • Çoklu ekran desteği

db.py Python

  • SQLite veritabanı yönetimi
  • Kayıt saklama ve silme politikası
  • Erişim günlüğü

Veritabanı Şeması (SQLite)

-- Sınav oturumları
CREATE TABLE exam_sessions (
    id          INTEGER PRIMARY KEY,
    started_at  TEXT NOT NULL,
    ended_at    TEXT,
    student_id  TEXT,       -- Anonim tanımlayıcı
    camera_ip   TEXT,
    status      TEXT DEFAULT 'ACTIVE'
);

-- Belge sayfaları
CREATE TABLE page_captures (
    id          INTEGER PRIMARY KEY,
    session_id  INTEGER REFERENCES exam_sessions(id),
    page_num    INTEGER,
    captured_at TEXT NOT NULL,
    image_path  TEXT,
    ocr_text    TEXT,
    status      TEXT DEFAULT 'PARTIAL'  -- PARTIAL/COMPLETE/UNCERTAIN
);

-- Cevap anahtarı
CREATE TABLE answer_keys (
    id          INTEGER PRIMARY KEY,
    session_id  INTEGER REFERENCES exam_sessions(id),
    question_no INTEGER,
    ocr_answer  TEXT,       -- OCR'dan okunan
    verified    INTEGER DEFAULT 0,
    corrected   TEXT,       -- Gözetmen düzeltmesi (varsa)
    verified_at TEXT
);

-- Aktivite olayları
CREATE TABLE activity_events (
    id          INTEGER PRIMARY KEY,
    session_id  INTEGER REFERENCES exam_sessions(id),
    event_type  TEXT NOT NULL,  -- WRITE_START, WRITE_END, PAUSE, ERASE, PAGE_TURN
    timestamp   TEXT NOT NULL,
    page_num    INTEGER,
    question_no INTEGER,
    duration_ms INTEGER,
    metadata    TEXT            -- JSON ek bilgi
);

-- Soru zamanlamaları
CREATE TABLE question_timings (
    id              INTEGER PRIMARY KEY,
    session_id      INTEGER REFERENCES exam_sessions(id),
    question_no     INTEGER,
    total_time_ms   INTEGER,
    write_time_ms   INTEGER,
    pause_time_ms   INTEGER,
    erase_time_ms   INTEGER,
    first_touch_at  TEXT,
    last_touch_at   TEXT
);

-- Erişim günlüğü
CREATE TABLE access_log (
    id          INTEGER PRIMARY KEY,
    accessed_at TEXT NOT NULL,
    user_role   TEXT,       -- INSTRUCTOR, ADMIN
    action      TEXT,
    session_id  INTEGER
);

İletişim Protokolleri

ESP32-S3 → MacBook

Protokol: HTTP MJPEG Akışı

Endpoint: http://<ESP32_IP>:81/stream

Format: multipart/x-mixed-replace; JPEG kareleri

Çözünürlük: 640×480 @ 5-10 fps

Bant genişliği: ~2-4 Mbps

MacBook → ESP32-C3 Ekran

Protokol: WebSocket (JSON)

Port: 8765

Mesaj tipleri:

  • ANSWER_KEY — Soru/cevap çifti göster
  • TIMING_UPDATE — Süre çubukları güncelle
  • MODE_SWITCH — Mod değiştir
  • STATUS — Durum bilgisi

WebSocket Mesaj Formatı (MacBook → Ekran)

// Cevap anahtarı modu
{
  "type": "ANSWER_KEY",
  "question": 3,
  "total": 10,
  "ocr_text": "F = m × a",
  "confidence": 0.87
}

// Zamanlama güncelleme
{
  "type": "TIMING_UPDATE",
  "questions": [
    {"q": 1, "write": 180, "pause": 45, "erase": 0, "active": false},
    {"q": 2, "write": 95,  "pause": 12, "erase": 8, "active": true},
    {"q": 3, "write": 0,   "pause": 0,  "erase": 0, "active": false}
  ],
  "current_page": 1,
  "total_pages": 3,
  "elapsed": "00:24:15"
}

// Düğme yanıtı (Ekran → MacBook)
{
  "type": "BUTTON",
  "action": "CONFIRM" | "CORRECT" | "SKIP",
  "question": 3,
  "correction": "F = m · a"  // sadece CORRECT'te
}
