Adım 1: Düğme Kamera Hazırlama

1.1 — Kamera Modülünü Ayırma

ESP32-CAM kartının üzerindeki OV2640 kamera modülünü dikkatlice çıkarın:

  1. FPC konnektörün siyah kilit klipsini yukarı kaldırın (nazikçe, kırmayın)
  2. Kamera modülünü düz bir şekilde yavaşça çekin
  3. Bu kamerayı yedek olarak saklayın (test için lazım olabilir)

1.2 — Uzun FPC Kablo ile Yeni Kamera Takma

Satın aldığınız yeni OV2640 modülünü FPC uzatma kablosuyla bağlayın:

  1. FPC uzatma kablosunun bir ucunu yeni OV2640 modülüne takın
  2. Diğer ucunu ESP32-CAM kartının konnektörüne takın
  3. Her iki taraftaki klipsleri sıkıca kapatın
  4. Kameranın görüntü verdiğini test edin (Adım 4'ten sonra)
FPC Kablo Uyumluluğu: ESP32-CAM, 24 pin, 0.5mm pitch FPC konnektör kullanır. Kablo alırken "aynı yön kontaklar" (same side) mı "ters yön" (opposite side) mı kontrol edin. ESP32-CAM ve OV2640 genelde aynı yön kullanır.

1.3 — Düğme Kasası Yapımı

Kamera modülünü düğme görünümünde gizlemek için:

Yöntem A: 3D Baskı Kasa

  • Çap: 20-25mm, yükseklik: 6-8mm
  • Ortada 3mm lens deliği (pin-hole tarzı)
  • 4 köşede dikiş deliği (yakaya dikmek için)
  • Arka tarafta FPC kablo çıkış yarığı
  • STL dosyasını Thingiverse'de "button camera case" arayarak bulabilir veya kendiniz tasarlayabilirsiniz (TinkerCAD/Fusion 360)
  • Türkiye'de 3D baskı hizmeti: Robotistan, N11'deki 3D baskı satıcıları, yerel maker space'ler

Yöntem B: Büyük Düğme Hack (3D Yazıcısız)

  • 25-30mm çapında büyük plastik/metal düğme alın (tuhafiyeciden)
  • Ortasına 3mm matkap ile delik açın (lens için)
  • Arkasını oyarak kamera modülünü yerleştirin
  • Sıcak silikonla sabitleyin
  • FPC kabloyu düğmenin kenarından çıkarın

Adım 2: Verici Ünitesi Montajı

2.1 — ESP32-CAM Güç Bağlantısı (Seçenek A)

ESP32-CAM kartını USB powerbank ile besleyeceksiniz:

  1. ESP32-CAM-MB (programlayıcı) kartını ESP32-CAM'in altına takın
  2. Micro-USB/Type-C kabloyu powerbank'a bağlayın
  3. Bu kombo cepte veya kemere klipsli küçük bir çantada taşınır

Boyut: ESP32-CAM + MB: ~55 × 27 × 12mm. Powerbank: ~90 × 60 × 13mm. Toplam cepte rahat taşınır.

2.2 — XIAO Güç Bağlantısı (Seçenek B)

XIAO ESP32S3 Sense çok küçük olduğu için daha kompakt bir çözüm mümkün:

  1. LiPo pili XIAO'nun arkasındaki JST konnektöre takın
  2. Isı çekmeli makaronla pil kablolarını sabitleyin
  3. Toplam boyut: ~45 × 25 × 12mm (cüzdan boyutundan küçük)

Adım 3: Gözetmen Ekranı Montajı

3.1 — ESP32-C3 + TFT Kablolama

ESP32-C3 Super Mini'yi ILI9341 2.4" TFT ekrana SPI ile bağlayın:

TFT PinESP32-C3 PinAçıklama
VCC3.3VGüç (3.3V kullanın, 5V değil!)
GNDGNDToprak
CSGPIO 7Chip Select
RESETGPIO 10Reset
DC/RSGPIO 6Data/Command
SDI (MOSI)GPIO 5SPI Data In
SCKGPIO 4SPI Clock
LEDGPIO 8Arka ışık (veya 3.3V'a direk)
Dikkat: ILI9341 modüllerinin bazıları 5V toleranslı, bazıları değil. 3.3V kullanmak her durumda güvenlidir. Modülün arkasındaki voltaj regülatörünü kontrol edin.

3.2 — Düğme Bağlantısı

3 adet dokunsal düğmeyi bağlayın (pull-up dirençlerine gerek yok, dahili pull-up kullanılacak):

DüğmeESP32-C3 Pinİşlev
Düğme 1 (Yeşil)GPIO 0Onayla (✓)
Düğme 2 (Sarı)GPIO 1Düzelt (✎)
Düğme 3 (Gri)GPIO 2Atla / İleri (»)

Her düğmenin bir bacağı GPIO pinine, diğer bacağı GND'ye bağlanır. Firmware'de INPUT_PULLUP kullanılır.

3.3 — Güç Devresi

  1. TP4056 modülünün OUT+ ve OUT- çıkışlarını ESP32-C3'ün 3.3V ve GND pinlerine bağlayın
  2. LiPo pilin kırmızı (+) telini TP4056'nın BAT+'ına, siyah (-) telini BAT-'ına lehimleyin
  3. TP4056'nın USB girişi şarj için kullanılır
LiPo güvenliği: Pil kabloları asla kısa devre ettirilmemelidir. Lehim noktalarını ısı çekmeli makaronla izole edin. TP4056'nın koruma devreli versiyonunu kullanın (DW01A çipli).

3.4 — Kasa İçine Yerleştirme

Kart seçimi: AI Thinker ESP32-CAM

#include "esp_camera.h"
#include <WiFi.h>
#include <WebServer.h>

// ---- WiFi Ayarları ----
const char* ssid = "SINAV_AG";
const char* password = "gozlem2026";

// ---- AI-Thinker ESP32-CAM Pin Tanımları ----
#define PWDN_GPIO_NUM     32
#define RESET_GPIO_NUM    -1
#define XCLK_GPIO_NUM      0
#define SIOD_GPIO_NUM     26
#define SIOC_GPIO_NUM     27
#define Y9_GPIO_NUM       35
#define Y8_GPIO_NUM       34
#define Y7_GPIO_NUM       39
#define Y6_GPIO_NUM       36
#define Y5_GPIO_NUM       21
#define Y4_GPIO_NUM       19
#define Y3_GPIO_NUM       18
#define Y2_GPIO_NUM        5
#define VSYNC_GPIO_NUM    25
#define HREF_GPIO_NUM     23
#define PCLK_GPIO_NUM     22

WebServer server(80);

void startCamera() {
  camera_config_t config;
  config.ledc_channel = LEDC_CHANNEL_0;
  config.ledc_timer = LEDC_TIMER_0;
  config.pin_d0 = Y2_GPIO_NUM;
  config.pin_d1 = Y3_GPIO_NUM;
  config.pin_d2 = Y4_GPIO_NUM;
  config.pin_d3 = Y5_GPIO_NUM;
  config.pin_d4 = Y6_GPIO_NUM;
  config.pin_d5 = Y7_GPIO_NUM;
  config.pin_d6 = Y8_GPIO_NUM;
  config.pin_d7 = Y9_GPIO_NUM;
  config.pin_xclk = XCLK_GPIO_NUM;
  config.pin_pclk = PCLK_GPIO_NUM;
  config.pin_vsync = VSYNC_GPIO_NUM;
  config.pin_href = HREF_GPIO_NUM;
  config.pin_sccb_sda = SIOD_GPIO_NUM;
  config.pin_sccb_scl = SIOC_GPIO_NUM;
  config.pin_pwdn = PWDN_GPIO_NUM;
  config.pin_reset = RESET_GPIO_NUM;
  config.xclk_freq_hz = 20000000;
  config.pixel_format = PIXFORMAT_JPEG;
  config.frame_size = FRAMESIZE_VGA;  // 640x480
  config.jpeg_quality = 12;
  config.fb_count = 2;

  esp_err_t err = esp_camera_init(&config);
  if (err != ESP_OK) {
    Serial.printf("Kamera hatasi: 0x%x\n", err);
    return;
  }
}

void handleStream() {
  WiFiClient client = server.client();
  String response = "HTTP/1.1 200 OK\r\n"
    "Content-Type: multipart/x-mixed-replace; "
    "boundary=frame\r\n\r\n";
  client.print(response);

  while (client.connected()) {
    camera_fb_t *fb = esp_camera_fb_get();
    if (!fb) continue;

    client.printf("--frame\r\n"
      "Content-Type: image/jpeg\r\n"
      "Content-Length: %u\r\n\r\n", fb->len);
    client.write(fb->buf, fb->len);
    client.print("\r\n");
    esp_camera_fb_return(fb);
  }
}

void setup() {
  Serial.begin(115200);
  startCamera();

  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.printf("\nIP: %s\n", WiFi.localIP().toString().c_str());

  server.on("/stream", handleStream);
  server.begin();
}

void loop() {
  server.handleClient();
}

#include <WiFi.h>
#include <ArduinoWebsockets.h>
#include <ArduinoJson.h>
#include <TFT_eSPI.h>
#include <SPI.h>

using namespace websockets;

const char* ssid = "SINAV_AG";
const char* password = "gozlem2026";
const char* ws_host = "192.168.1.100"; // Mac IP
const int ws_port = 8765;

TFT_eSPI tft = TFT_eSPI();
WebsocketsClient client;

// Dugmeler
#define BTN_CONFIRM 0
#define BTN_CORRECT 1
#define BTN_SKIP    2

int currentMode = 0;  // 0=cevap anahtari, 1=izleme
int currentQ = 1;
int totalQ = 0;

void drawAnswerKey(int qNum, int total, const char* text,
                   float conf) {
  tft.fillScreen(TFT_BLACK);
  tft.setTextColor(TFT_WHITE);
  tft.setTextSize(2);
  tft.setCursor(10, 10);
  tft.printf("Soru %d/%d", qNum, total);

  tft.setTextSize(1);
  tft.setCursor(10, 40);
  tft.setTextColor(TFT_CYAN);
  tft.print("OCR Cevap:");

  tft.setTextSize(2);
  tft.setCursor(10, 60);
  tft.setTextColor(TFT_GREEN);
  tft.print(text);

  // Guven cubuğu
  int barW = (int)(200 * conf);
  uint16_t barColor = conf > 0.7 ? TFT_GREEN :
                      conf > 0.4 ? TFT_YELLOW : TFT_RED;
  tft.fillRect(10, 100, barW, 12, barColor);
  tft.drawRect(10, 100, 200, 12, TFT_DARKGREY);
  tft.setTextSize(1);
  tft.setCursor(215, 102);
  tft.printf("%%%d", (int)(conf * 100));

  // Dugme etiketleri
  tft.setCursor(10, 130);
  tft.setTextColor(TFT_GREEN);  tft.print("[1] Onayla  ");
  tft.setTextColor(TFT_YELLOW); tft.print("[2] Duzelt  ");
  tft.setTextColor(TFT_WHITE);  tft.print("[3] Atla");
}

void drawMonitor(JsonDocument& doc) {
  tft.fillScreen(TFT_BLACK);
  tft.setTextColor(TFT_WHITE);
  tft.setTextSize(1);

  // Baslik
  tft.setCursor(10, 5);
  tft.printf("Sayfa: %d/%d  Sure: %s",
    doc["current_page"].as<int>(),
    doc["total_pages"].as<int>(),
    doc["elapsed"].as<const char*>());

  // Soru zamanlama cubuklari
  JsonArray questions = doc["questions"].as<JsonArray>();
  int y = 25;
  for (JsonObject q : questions) {
    int qn = q["q"].as<int>();
    int wr = q["write"].as<int>();
    int pa = q["pause"].as<int>();
    int er = q["erase"].as<int>();
    bool active = q["active"].as<bool>();

    tft.setCursor(5, y);
    tft.setTextColor(active ? TFT_CYAN : TFT_DARKGREY);
    tft.printf("S%d", qn);

    int total = wr + pa + er;
    if (total > 0) {
      int maxW = 180;
      int wW = (wr * maxW) / total;
      int pW = (pa * maxW) / total;
      int eW = maxW - wW - pW;

      tft.fillRect(30, y, wW, 8, TFT_GREEN);
      tft.fillRect(30 + wW, y, pW, 8, TFT_YELLOW);
      if (eW > 0)
        tft.fillRect(30 + wW + pW, y, eW, 8, TFT_RED);
    }
    y += 14;
    if (y > 140) break;
  }
}

void onMessage(WebsocketsMessage msg) {
  JsonDocument doc;
  deserializeJson(doc, msg.data());

  const char* type = doc["type"];
  if (strcmp(type, "ANSWER_KEY") == 0) {
    currentMode = 0;
    currentQ = doc["question"].as<int>();
    totalQ = doc["total"].as<int>();
    drawAnswerKey(currentQ, totalQ,
      doc["ocr_text"].as<const char*>(),
      doc["confidence"].as<float>());
  }
  else if (strcmp(type, "TIMING_UPDATE") == 0) {
    currentMode = 1;
    drawMonitor(doc);
  }
  else if (strcmp(type, "MODE_SWITCH") == 0) {
    currentMode = doc["mode"].as<int>();
  }
}

void checkButtons() {
  static unsigned long lastPress = 0;
  if (millis() - lastPress < 300) return;

  JsonDocument resp;
  bool send = false;

  if (digitalRead(BTN_CONFIRM) == LOW) {
    resp["type"] = "BUTTON";
    resp["action"] = "CONFIRM";
    resp["question"] = currentQ;
    send = true;
  }
  else if (digitalRead(BTN_CORRECT) == LOW) {
    resp["type"] = "BUTTON";
    resp["action"] = "CORRECT";
    resp["question"] = currentQ;
    send = true;
  }
  else if (digitalRead(BTN_SKIP) == LOW) {
    resp["type"] = "BUTTON";
    resp["action"] = "SKIP";
    resp["question"] = currentQ;
    send = true;
  }

  if (send) {
    String out;
    serializeJson(resp, out);
    client.send(out);
    lastPress = millis();
  }
}

void setup() {
  Serial.begin(115200);
  pinMode(BTN_CONFIRM, INPUT_PULLUP);
  pinMode(BTN_CORRECT, INPUT_PULLUP);
  pinMode(BTN_SKIP, INPUT_PULLUP);

  tft.init();
  tft.setRotation(1);
  tft.fillScreen(TFT_BLACK);
  tft.setTextColor(TFT_WHITE);
  tft.setTextSize(2);
  tft.setCursor(20, 50);
  tft.print("Baglaniyor...");

  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) delay(500);

  client.onMessage(onMessage);

  String wsUrl = String("ws://") + ws_host + ":"
    + String(ws_port);
  client.connect(wsUrl);

  tft.fillScreen(TFT_BLACK);
  tft.setCursor(20, 50);
  tft.print("Hazir");
}

void loop() {
  client.poll();
  checkButtons();
}

Adım 6: WiFi Ağı Kurulumu

6.1 — Özel WiFi Ağı (Önerilen)

Sınav ortamında ayrı bir WiFi ağı kurmak en güvenilir yöntemdir:

  1. Küçük bir travel router veya Mac'in Hotspot özelliğini kullanın
  2. SSID: SINAV_AG (veya istediğiniz bir isim)
  3. Şifre: güçlü bir şifre seçin
  4. Kanal: 2.4 GHz (ESP32 sadece 2.4 GHz destekler)
  5. Tüm cihazları bu ağa bağlayın: ESP32-CAM, ESP32-C3 ekran, MacBook

6.2 — Mac Hotspot ile (En Basit)

  1. Mac'te: Sistem Ayarları → Paylaşım → İnternet Paylaşımı
  2. "Paylaşılacak bağlantı": Ethernet veya Thunderbolt
  3. "Kullanan bilgisayarlar": Wi-Fi
  4. Wi-Fi Seçenekleri → Kanal: 6 (veya 1/11), Güvenlik: WPA2
  5. İnternet Paylaşımı'nı açın
Not: Mac hotspot modunda iken WiFi ile internete bağlanamaz. İnternet gerekiyorsa Ethernet/Thunderbolt ile bağlantı sağlayın veya ayrı bir router kullanın.

Adım 7: Test ve Kalibrasyon

7.1 — Kamera Testi

  1. ESP32-CAM'i çalıştırın ve IP adresini not edin
  2. Tarayıcıda açın: http://<ESP32_IP>/stream
  3. Canlı görüntü gelmelidir. Kontrol edin:
    • Kağıt üzerindeki yazı okunaklı mı?
    • FPC kablo ile görüntü kalitesi düşmüş mü?
    • Eğimli masada kağıdın tamamı görünüyor mu?
    • El hareketleri net seçiliyor mu?

7.2 — Ekran Testi

  1. ESP32-C3 ekranı çalıştırın
  2. "Bağlanıyor..." ardından "Hazır" yazmalıdır
  3. Mac'te WebSocket sunucuyu başlatın
  4. Test mesajı gönderin: 
    python3 -c "
import asyncio, websockets, json
async def test():
    async with websockets.serve(handler, '0.0.0.0', 8765):
        await asyncio.Future()
async def handler(ws):
    msg = json.dumps({
        'type': 'ANSWER_KEY',
        'question': 1, 'total': 5,
        'ocr_text': 'F = m x a',
        'confidence': 0.92
    })
    await ws.send(msg)
    resp = await ws.recv()
    print('Dugme yaniti:', resp)
asyncio.run(test())
"
  5. Ekranda "Soru 1/5" ve "F = m x a" görünmelidir
  6. Yeşil düğmeye basın → Mac'te "CONFIRM" yanıtı gelmelidir

7.3 — Uçtan Uca Test

  • Düğme kamerayı yakaya takın, eğimli masada oturun
  • Kağıda yazı yazın, Mac'te görüntüyü kontrol edin
  • FPC kabloyu hareket ettirin, görüntü kesilmemeli
  • Gözetmen ekranında cevap anahtarı görüntülensin
  • 3 düğmeyi test edin: Onayla, Düzelt, Atla
  • Son sorudan sonra otomatik izleme moduna geçiş
  • Pil ömrü: verici en az 2 saat, ekran en az 4 saat
  • WiFi menzil: duvar arkası en az 10 metre

Sorun Giderme

Kamera görüntü vermiyor

  • FPC kablo tam oturmuş mu? Klipsi sıkıca kapatın
  • FPC kablo yönü doğru mu? Kontaklar aynı tarafta olmalı
  • ESP32-CAM'in LED'i yanıyor mu? Güç geldiğinden emin olun
  • Seri Monitör'de "Kamera hatası: 0x..." mesajı varsa kablo hasarlı olabilir
  • Orijinal kısa FPC kablo ile test edin → kablo mu yoksa modül mü sorun?

WiFi bağlantı kurulamıyor

  • SSID ve şifre doğru mu? Büyük/küçük harf duyarlıdır
  • Router 2.4 GHz mi? ESP32 5 GHz desteklemez
  • Cihazlar arası mesafe çok mu fazla? 10m içinde test edin
  • Mac ve ESP32'ler aynı ağda mı? ping <ESP32_IP> ile test edin

Ekran beyaz/boş kalıyor

  • SPI kablolama doğru mu? Özellikle MOSI ve SCK pinleri
  • User_Setup.h pin tanımları doğru mu?
  • TFT modülün VCC'si 3.3V'a mı bağlı?
  • LED/BL pini bağlı mı? Arka ışık olmadan ekran karanlık kalır
  • tft.setRotation(1) deneyin — yatay/dikey yön değişir

WebSocket bağlantı hatası

  • Mac'in IP adresi değişmiş olabilir → ifconfig en0 ile kontrol edin
  • Python WebSocket sunucu çalışıyor mu? Port 8765 açık mı?
  • Mac güvenlik duvarı WebSocket'i engelliyor olabilir → Sistem Ayarları → Güvenlik Duvarı
  • ESP32-C3 firmware'deki ws_host IP'si güncel mi?

OCR doğruluğu düşük

  • Kamera çözünürlüğünü artırın: FRAMESIZE_SVGA (800×600) deneyin
  • JPEG kalitesini artırın: jpeg_quality = 8 (düşük değer = yüksek kalite)
  • Aydınlatma yeterli mi? Sınav salonunda ek ışık gerekebilir
  • Tesseract dil paketi doğru mu? --oem 3 --psm 6 -l tur parametrelerini deneyin
  • El yazısı OCR'u her zaman düşük olur → gözetmen doğrulaması bu yüzden zorunlu
